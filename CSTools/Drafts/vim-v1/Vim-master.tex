\chapter*{Preface}

Vim is not a text editor with a strange set of shortcuts. It is a small
\emph{language} for describing edits, and the keyboard is its alphabet.
Once you can read a sentence like \key{c} \key{i} \key{(} as \emph{``change
	inside parentheses''}, the hundreds of commands collapse into a grammar with
perhaps thirty words. That grammar is the real subject of this note; everything
else is vocabulary.

The first five chapters cover Vim proper --- modes, motions, operators, text
objects, registers, macros, buffers and windows. Everything there works
unchanged in Vim, Neovim, and in the Vim emulation layer of almost every other
editor, so the investment never expires. \autoref{ch:nvim} onwards covers what
Neovim adds on top: a Lua configuration language, a built-in LSP client,
Treesitter, an embedded terminal, and the plugin ecosystem that grew around
them. \autoref{ch:setup} walks through the configuration actually installed on
this machine (LazyVim + VimTeX + LuaSnip), so the abstractions have something
concrete to point at.

For anything this note leaves out, the authoritative sources are Vim's own
help files \cite{vimdoc} and Neovim's \cite{nvimdoc}, both readable inside the
editor with \cmd{:help}. For a book-length treatment of the grammar in
\autoref{ch:grammar}, Drew Neil's \emph{Practical Vim} \cite{neil2015practicalvim}
is the standard recommendation.

A word on how to read this. Do not try to memorise the tables. Pick three or
four commands per chapter, force yourself to use them for a week until they
become involuntary, and only then come back for more. The \emph{Try it} boxes
exist for exactly this purpose. Vim's learning curve is not steep so much as it
is \emph{long}, and the only thing that fails is trying to climb it all at once.

\begin{notation}
	Keystrokes are typeset as keycaps: \key{d} \key{w} means ``press \texttt{d},
	then \texttt{w}'' --- Vim commands are sequences, not chords. Following Vim's
	own help files, \key{<C-d>} means Control held with \texttt{d},
	\key{<S-d>} means Shift, \key{<CR>} is Enter, \key{<Esc>} is Escape and
	\key{<Space>} is the space bar. Commands typed on the \key{:} command line
	are written inline as \cmd{:write}, and file paths as
	\file{\textasciitilde/.config/nvim/init.lua}.
\end{notation}
